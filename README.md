# Mamoun Hisham

Self-taught full-stack developer. I learned by building real things end to end, then sharpened that through a bootcamp under a senior developer's mentorship — code review, architecture decisions, and all the habits that only come from someone reading your work closely.

Most of my time goes into shipping: web platforms with real users, backend systems that hold up under load, and mobile apps that talk to servers I run myself. Lately that's meant [Moch](https://github.com/SoftLand-Tech/Moch) — an open-source React Native client that puts a self-hosted AI agent in your pocket, with streaming replies, approvals, scheduled automations, and a pairing flow simple enough to be one shell command.

What I care about most is the part nobody sees: clean data models, sensible boundaries between services, auth and billing done properly. The UI matters, but the parts that hurt later are the ones built carelessly underneath.

I work on a Linux setup I've tuned myself, and I'd rather automate a task a second time than do it manually twice.
